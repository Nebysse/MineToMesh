# MC glTF Exporter 0.2.0 Generic Render Compatibility Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release MC glTF Exporter 0.2.0 with generic render-backend fallback capture, GPU texture readback, correct zero-vertex placeholder policy, and simultaneous glTF plus quad-preserving OBJ output.

**Architecture:** Capture immutable source primitives that retain their original Minecraft topology, then feed the same batches to independent streaming glTF and OBJ writers. Wrap registered entity and block-entity renderers in scoped backend adapters, beginning with a reflection-isolated Flywheel 1.x adapter, and resolve textures through resource, CPU dynamic, GPU readback, and checkerboard providers. Combine static and auxiliary capture outcomes before deciding whether a placeholder is justified.

**Tech Stack:** Java 21, Minecraft 1.21.1, NeoForge 21.1.244, JUnit 5, Gson, LWJGL/OpenGL through Mojang `GlStateManager` and `NativeImage`, glTF 2.0, Wavefront OBJ/MTL.

**Execution policy:** The project owner disabled subagent use. Execute inline in an isolated Git worktree with `superpowers:executing-plans`, preserving strict red-green-refactor TDD and one commit per task.

```java
public record PrimitiveData(
        List<Vertex> vertices,
        PrimitiveMode sourceMode,
        int[] streamVertexCounts,
        MaterialKey material) {
    public PrimitiveData {
        vertices = List.copyOf(vertices);
        Objects.requireNonNull(sourceMode, "sourceMode");
        streamVertexCounts = streamVertexCounts.clone();
        Objects.requireNonNull(material, "material");
        int covered = 0;
        for (int count : streamVertexCounts) {
            if (count <= 0) {
                throw new IllegalArgumentException("Stream vertex count must be positive");
            }
            covered = Math.addExact(covered, count);
        }
        if (covered != vertices.size()) {
            throw new IllegalArgumentException(
                    "Stream vertex counts cover " + covered + " of " + vertices.size() + " vertices");
        }
    }

    @Override
    public int[] streamVertexCounts() {
        return streamVertexCounts.clone();
    }
}
```

```java
public static ConvertedTopology convert(PrimitiveData primitive, String objectId) {
    List<Integer> indices = new ArrayList<>();
    int offset = 0;
    int gltfMode = gltfMode(primitive.sourceMode());
    for (int count : primitive.streamVertexCounts()) {
        ConvertedTopology stream = convertToExplicitTopology(
                primitive.sourceMode(), count, objectId);
        for (int index : stream.indices()) {
            indices.add(offset + index);
        }
        offset += count;
    }
    return new ConvertedTopology(
            gltfMode,
            indices.stream().mapToInt(Integer::intValue).toArray(),
            collectDiagnostics(primitive, objectId));
}
```
