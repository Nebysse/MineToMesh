# MineToMesh 1.5.0

MineToMesh 1.5.0 是 Minecraft 1.21.10 NeoForge 移植版本。功能与 1.4.0 对齐，面向 NeoForge 21.10.64，随渲染与输入管线重构重写了所有 MC 版本耦合代码。1.21.1（NeoForge）与 26.2（Fabric Alpha）构建保持不变。

## 版本适配

- 目标 Minecraft 1.21.10、NeoForge 21.10.64、Java 21；mods.toml 版本区间 `[1.21.10,1.21.11)`。
- 区块加载改用 1.21.10 的 Ticket 系统：`new TicketType(NO_TIMEOUT, FLAG_LOADING)` 配合 `addTicketAndLoadWithRadius` / `removeTicketWithRadius`，加载完成由票据返回的 CompletableFuture 表示。
- 方块模型改走 `BlockStateModel.collectParts(level, pos, state, random, parts)`，渲染层由 `BlockModelPart.getRenderType(state)` 给出的 `ChunkSectionLayer` 判定；方块实体模型数据（旧 ModelData）由模型在 collectParts 中直接读取方块实体。
- 方块实体与实体渲染捕获改用 1.21.10 的渲染状态管线：`createRenderState` / `extractRenderState` / `submit(S, PoseStack, SubmitNodeCollector, CameraRenderState)`，几何经 `CapturingSubmitNodeCollector` 截获 submitModel / submitModelPart / submitCustomGeometry 节点。
- 渲染语义检查重写：`RenderType` 的 CompositeState 不再暴露，改为反射读取名称与合成状态，并结合 `RenderPipeline.getBlendFunction()`（BlendFunction.ADDITIVE / LIGHTNING）判定叠加混合；ChunkSectionLayer 走独立检查入口。
- 魔杖选区壳按 vanilla 世界边界同款管线绘制：`DefaultVertexFormat.POSITION_TEX` + `RenderPipelines.WORLD_BORDER` + `writeTransform` 动态 uniform 染色，输出到天气/主渲染目标。
- 纹理读回适配 blaze3d GPU 设备：`AbstractTexture` 不再暴露 GL id，从 `GlTexture.glId()` 桥接；`NativeImage.downloadTexture` 移除，改为直接 `glGetTexImage`；`getPixel` 返回 ARGB 打包。
- GUI 输入适配 `KeyEvent` / `CharacterEvent`；`GuiGraphics.blit` 使用显式 `RenderPipeline`（GUI_TEXTURED）与内置拉伸重载，九宫格不再依赖 pose 变换。
- 内容注册适配 1.21.10：Block/Item 属性显式 `setId(ResourceKey)`；`BlockEntityType` 直接构造；`EntityType.Builder.build` 使用注册表键。
- 网络与杂项：客户端上送改走 `ClientPacketDistributor.sendToServer`；资源重载事件更名为 `AddClientReloadListenersEvent`；`InteractionResult` 密封接口取代 `InteractionResultHolder`；世界高度语义切换为 `getMinY` / `getMaxY`（含端 +1）；ClickEvent 使用 `RunCommand` 记录。

## 测试夹具

- testmod 的 ModelData 夹具重写为 `TestBlockStateModel`（collectParts 直接断言方块实体 phase=1，几何层 CUTOUT + 空 TRANSLUCENT 部件），继续覆盖多渲染层与方块实体上下文传递。
- 游戏内测试适配 1.21.10 注册表驱动测试框架：测试函数经 `DeferredRegister` 注册进 `TEST_FUNCTION`，测试实例经 `RegisterGameTestsEvent` 注册（@GameTest 注解已移除）。
- `GpuResidentTexture` 经 `GpuDevice.createTexture` 分配；实体/方块实体测试渲染器改为 submit 节点输出。

165 项 JUnit 测试与专用服务器冒烟通过；1.21.1 与 26.2 平台构建回归通过。

## 安装

1. 安装 Minecraft 1.21.10 与 NeoForge 21.10.64。
2. 移除客户端和服务端 `mods/` 目录中的旧 MineToMesh JAR。
3. 在客户端和服务端同时安装 `MineToMesh-1.5.0-neoforge-1.21.10.jar`。
