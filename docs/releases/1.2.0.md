# MineToMesh 1.2.0

MineToMesh 1.2.0 修复普通方块模型中精确重叠面的黑面与闪烁，加入保留 Quad 的 OpenUSD（USDA）导出，并提供按世界或服务器隔离、跨重启保存的锁定选区预览。

## 修改内容

### 精确共面 Quad 分层

- 对同一方块内坐标完全一致的 `BakedQuad` 建立稳定几何指纹，兼容顶点循环移位与反向排列。
- 第一层保持原位，后续重叠层沿各自法线以 `1/1024` 格递增偏移。
- 保留 Powered Rail、草方块底层与 Tint Overlay 等全部几何，不通过删面规避 Z-fighting。
- 检测只作用于普通方块模型；流体、实体和方块实体渲染器输出不受影响。
- `report.json` schema 升至 3，新增 `geometryAdjustments` 聚合统计与退化法线诊断。

### USDA / OpenUSD 导出

- 每次导出生成 glTF、BIN、USDA、外部 PNG 纹理、材质侧车文件和 `report.json`。
- glTF 继续按规范三角化；USDA 保留源 Quad，所有 Mesh 固定 `subdivisionScheme = "none"`。
- USDA 舞台使用 Y-Up、`metersPerUnit = 1`、外部纹理和 UsdPreviewSurface 材质。
- 保留 `Chunks`、`BlockEntities`、`Entities`、`Placeholders`、`Overlays` 层级；动态方块实体继续按完整 `MaterialKey` 全局合批。
- 顶点 Tint、Cutout、Blend、双面和发光写入 USDA 材质网络；最近邻语义写入 `minetomesh:samplerMode` 与材质 Sidecar，Blender 未自动恢复时需手动设为 `Closest`。
- 导出成功、取消或失败后清理 `.usdapart` 流式临时片段。
- 当前版本立即移除 OBJ/MTL 输出及实现，不提供兼容开关。

### 持久锁定选区

- 导出 GUI 提供三个独立开关：`手持预览`、`锁定选区`、`导出玩家`。
- 锁定选区无需持续手持魔杖；相同的手持与锁定快照每帧去重，不同快照可同时显示。
- 每个单人存档或多人服务器保存一个锁定记录，切换维度时只隐藏，返回原维度后恢复。
- 配置写入 `.minecraft/config/minetomesh/locked-selections.json`，使用 SHA-256 Profile 键隐藏原始路径和服务器地址。
- 配置通过同目录临时文件原子替换；损坏 JSON 会隔离为 `locked-selections.json.corrupt-*`。
- 锁定状态完全位于客户端，不修改魔杖组件、命令协议或服务端网络载荷。

## 输出结构

```text
minetomesh-exports/<名称>/
├─ <名称>.gltf
├─ <名称>.bin
├─ <名称>.usda
├─ report.json
├─ textures/
└─ materials/
```

## 安装

1. 安装 Minecraft 1.21.1 与 NeoForge 21.1.244。
2. 移除客户端和服务端 `mods/` 目录中的旧 MineToMesh JAR。
3. 在客户端和服务端同时安装 `MineToMesh-1.2.0.jar`。

已由旧版本生成的 OBJ 文件不会被修改或删除；需要 USDA 时请使用 1.2.0 重新导出。
