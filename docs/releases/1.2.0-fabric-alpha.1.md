# MineToMesh 1.2.0-fabric-alpha.1

首个 Minecraft 26.2 Fabric Alpha，同时保留 Minecraft 1.21.1 NeoForge `1.2.0` 正式版。

## 运行环境

- Minecraft 26.2
- Fabric Loader 0.19.3
- Fabric API 0.157.0+26.2
- Java 25
- 客户端和服务端均需安装 `MineToMesh-1.2.0-fabric-alpha.1+mc26.2.jar`

## 已移植功能

- 导出魔杖、独立 `wandId`、POS1/POS2、空气取点和服务端权威校验
- GUI、Unicode 名称输入、持有预览、持久锁定选区与世界隔离
- Fabric 自定义载荷、权限、菜单绑定、断线和资源重载生命周期
- 原版及 Fabric 模型方块、流体、方块实体和实体捕获
- 纹理资源、动态纹理、图集 UV 归一化与缺失纹理诊断
- glTF 2.0、BIN、USDA、PNG、材质侧车文件与 `report.json`
- 未加载区块跳过、6 ms 捕获预算、容量 2 的异步写入队列

## Alpha 限制

- 尚未声明 Minecraft 26.2 Flywheel 或其他第三方渲染后端兼容。无法取得 CPU 几何时使用占位体并记录诊断。
- Minecraft 26.2 的 GPU 后端不再公开 OpenGL 纹理 ID；资源纹理与仍保有 `NativeImage` 的动态纹理可直接导出，其余纹理回退到缺失纹理诊断。
- 自动化测试和专用服务器冒烟不能替代真实客户端、Blender、中文输入法与视觉验收；执行状态见 `docs/testing/manual-client-matrix.md`。

## 构建

```powershell
./gradlew.bat :fabric-26.2:test :fabric-26.2:build --no-configuration-cache
```

产物：`fabric-26.2/build/libs/MineToMesh-1.2.0-fabric-alpha.1+mc26.2.jar`
